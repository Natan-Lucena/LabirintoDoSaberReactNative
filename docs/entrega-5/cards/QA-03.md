# QA-03 — Acessibilidade

| Campo           | Valor                                                                             |
| --------------- | --------------------------------------------------------------------------------- |
| Bloco / onda    | F — Qualidade · E5-11                                                             |
| Classe / modelo | B · o Victor executa (manual); Sonnet/Codex para as correções pequenas que saírem |
| Estimativa      | M · 1 dia de teste + correções                                                    |
| Dependências    | NAV-05 (todas as telas reais); autorização do usuário para o emulador             |
| Quem executa    | Victor, com TalkBack no emulador ou no Android físico                             |

## 1. Objetivo

Garantir que as telas das Entregas 3 a 5 funcionam com leitor de tela, fonte grande e toque,
com atenção especial aos **jogos** (letras, cores e cartas), que são o ponto mais frágil.

## 2. Ambiente

Android com **TalkBack** ligado (Configurações → Acessibilidade), fonte em "Maior" e tamanho de
exibição grande; Expo Go; backend real. O roteiro base é o
[07-acessibilidade-qa03 da Entrega 3](../../entrega-3/testes/07-acessibilidade-qa03.md).

## 3. Roteiro

1. **Checklist por tela** (do roteiro da Entrega 3): rótulo de cada controle, ordem de leitura,
   alvo ≥ 44, contraste do texto, nada cortado com fonte grande, estado anunciado ("selecionado",
   "desativado").
2. **Telas novas da Entrega 5:** Equipe (cartão de convite, código soletrado), cadastro pelo
   convite, ficha com "Quem acompanha" e "Pendências", lista com filtros novos, Agenda mês (cada
   dia anuncia "N agendamentos"), série (prévia lida em texto), preferências de notificação
   (`Switch` com título), Central de ajuda (player e passos).
3. **Jogos:**
   - "Forme a palavra": "Letra A", "Espaço 2 de 4, vazio/preenchido com A"; dá para completar só
     com TalkBack.
   - "Associe as cores": cada amostra anuncia o nome da cor; a cor nunca é a única pista.
   - "Memória visual": carta anuncia "virada" / "aberta: {figura}"; dá para terminar com
     TalkBack.
4. Registrar cada problema com tela, elemento, o que o leitor disse e o esperado.

## 4. Critérios de saída

- Nenhum item **bloqueante** (não dá para concluir a tarefa com TalkBack ou com fonte grande)
  (AC-QA-03-01).
- Itens não bloqueantes viram issue com prioridade.

## 5. Evidências

Checklist preenchido em `docs/entrega-5/testes/08-acessibilidade.md`, com aparelho, versão do
Android, commit e capturas **fora do repositório**.

## 8. Riscos e perguntas em aberto

- **VoiceOver (iOS)** só com iPhone: fica na QA-04 ou pendente.
- Jogos com arrastar não entram (os da Entrega 5 são por toque); se algum usar gesto, precisa de
  alternativa por toque.

## 9. Fora do escopo
